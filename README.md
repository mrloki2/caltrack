# CALTRACK

> Minimalist Personal Calorie & Nutrition Engine

CALTRACK is a high-performance, dark-themed personal nutrition dashboard with real-time cooking-method intelligence and multi-item natural combo parsing.

## Key Features

- **Access Gate**: User Registration & Login with 4-6 digit numeric PIN.
- **Cooking Method Intelligence**: Differentiates calories between deep-frying, grilling, and boiling (e.g. หมูย่าง 240 kcal vs หมูทอด 380 kcal).
- **Multi-Item Parser**: Understands combination logs with quantities (e.g. `หมูปิ้ง 3 ไม้ ข้าวเหนียว 1 ห่อ กาแฟดำ`).
- **History Tracking**: Sub-tabs for Today vs Expandable Past History accordion.
- **Macro Breakdown**: Real-time Carbs, Protein, Fat, and Calorie calculations.
- **Biometric Baselines**: Live real-time BMR, TDEE, and BMI calculator.
- **Zero AI Buzzwords**: Clean, professional, and privacy-first local storage engine.

## Deployment

Deployed on Vercel and GitHub.
